# Calculator 1.0.1

Calculator 1.0.1 is a maintenance update to the first stable release.

## Changes since 1.0.0

- Tighter landscape spacing and reduced key/text sizes for compact landscape screens.
- RAD/DEG angle-mode toggle now restores its label and color from the saved
  angle mode after a device rotation.
- Landscape row 5 last key changed from an extra parenthesis to a closing
  parenthesis `)` (id `btnRparen2`).
- Removed an unused scientific background drawable.

## Highlights

- Standard calculator in portrait orientation.
- Scientific calculator activated automatically in landscape orientation.
- Responsive layouts for compact and regular phone screens.
- Premium light and dark themes.
- Calculation state retained when the device rotates.
- Only the equals key uses the permanent orange accent.
