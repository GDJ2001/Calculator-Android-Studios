# Calculator 1.0

Calculator 1.0 is the first stable release of the Android calculator.

## Highlights

- Clean standard calculator optimized for portrait use.
- Scientific calculator activated automatically in landscape orientation.
- Responsive layouts for compact and regular phone screens.
- Premium light and dark themes.
- Calculation state retained when the device rotates.
- Improved button hierarchy, spacing, readability, and touch targets.
- Only the equals key uses the permanent orange accent.

## Calculator Functions

- Addition, subtraction, multiplication, division
- Percentage
- Decimal calculations
- Backspace and clear all
- Trigonometric operations (sin, cos, tan, sin Minus1, cos Minus1, tan Minus1)
- Logarithmic operations (ln, log)
- Powers and roots (x2, x^y, sqrt)
- Constants (pi, e)
- Factorial (n!), reciprocal (1/x), sign toggle (PlusMinus)
- Parentheses
- RAD/DEG angle mode

## Important Behaviour

- Portrait orientation displays the standard calculator.
- Landscape orientation automatically displays scientific controls.
- No manual scientific-mode switch is required.

## Installation

1. Download the APK attached to this release.
2. Allow installation from the selected browser or file manager when Android requests permission.
3. Open the downloaded APK and complete installation.
